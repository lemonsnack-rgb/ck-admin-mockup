# 카피킬러 관리기 — 목업 (P0-B)

기획안(`docs/카피킬러_관리기_목업화면_구현_기획안.md`)과 기능단위명세를 기준으로 만든 **정적 클릭 목업**.
**기존 관리기(ck-adm.muhayu.com) 스타일을 그대로 복제**했다 — shadcn/ui 라이트 테마 · Pretendard · 흰 카드/사이드바 · 중립 회색 뱃지 · 근검정 primary · 우측정렬 필터바 · 중앙 페이지네이션.

## 실행
`index.html`(또는 `ck-domains.html`)을 브라우저로 연다. 별도 서버 불필요(정적 파일).
※ Pretendard 폰트는 CDN에서 로드(온라인). 오프라인이면 시스템 산세리프로 대체됨.

## 구조 원칙 (중요)
**기능 = 선택 축(상단 드롭다운), 정책 = 고정 컬럼.** 구 관리기(`campus.op.copykiller.com/admin`)처럼 "기능마다 컬럼 추가"하지 않는다. 신규 기능이 나와도 **드롭다운 항목만 추가**되고 표 컬럼은 불변. 현재 제어 대상 기능은 **`참고문헌 유효성 검증` 1개**.
- 정책 고정 컬럼(분리): `사용여부 · 이용구분 · 이용기간(시작~종료) · 일일한도 · 상태`. 사용여부{사용/미사용/미설정}와 상태{유효/만료/—}는 값 중복 없음.
- 미설정(개별정책 없음) 행도 **해석된 서비스 기본값(구체 기간·한도)을 `(기본)` 태그**로 표시.

## 셸(ck-adm 실측 반영)
사이드바: `CK 관리기·CM 관리기` 그룹 → **기능별 이용 제한 정책 관리** → `기본 적용 정책 설정`·`도메인별 정책 설정`. 하단 고정 `iwang@muhayu.com + 로그아웃`. 헤더에 패널 토글 + 브레드크럼(구분선), 카드 안 큰 타이틀 + `전체 N건`(citation/documents 스타일).

## 화면
| 파일 | 화면 | 설명 |
|---|---|---|
| `ck-domains.html` | **도메인별 정책 설정** | 기능 드롭다운 + 고정 컬럼 목록 · 검색/필터 · 행 수정 다이얼로그. 메인 진입 |
| `ck-features.html` | **기본 적용 정책 설정** | 기능 드롭다운 + 서비스 목록(번호/서비스명/기본사용여부/기본이용기간/기본일일한도) + 기본값 수정 다이얼로그 |

※ 일괄 지정·대시보드·변경 이력·도메인 단독 상세는 범위 제외(정책 변경은 목록 행 수정으로 처리).

## 공통
- `styles.css` : 디자인 토큰·컴포넌트(사이드바/카드/필터/테이블/뱃지/버튼/다이얼로그/스텝)
- `app.js` : 사이드바(CK/CM 메뉴그룹) 주입 · 다이얼로그/토스트 유틸
- 사이드바는 **CK 관리기·CM 관리기 별도 메뉴그룹**. 목업은 CK 화면만 구현(CM 링크는 비활성).

## 데이터
표시 데이터는 모두 **더미**다. 실제 API 연동은 P1 단계.
